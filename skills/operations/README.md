# Operations

Skills for managing Nexus infrastructure and operational workflows — nodes, processes, scheduled jobs, incident response, and email automation.

## Skills

| Skill | Description |
|-------|-------------|
| [node-ops](node-ops/) | Manage execution nodes — health checks, remote commands, process management, file transfers |
| [incident-response](incident-response/) | Structured troubleshooting for gateway, process, and job failures |
| [scheduled-reporting](scheduled-reporting/) | Create and manage recurring jobs, reports, and automated notifications |
| [node-deploy](node-deploy/) | Deploy or upgrade Nexus execution nodes (standard or lite) via SSH |
| [emailing](emailing/) | Manage inbox triage, reading, replies, forwarding, and attachments via Himalaya CLI |
