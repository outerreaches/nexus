# Autonomous AI Agents

Skills for delegating tasks to external AI agent CLIs (Codex, Claude Code, etc.) through Nexus shell tools.

Each skill defines preflight checks, execution mode selection, command patterns, guardrails, and a completion protocol for safe delegation.

## Skills

| Skill | Description |
|-------|-------------|
| [codex](codex/) | Delegate coding tasks to OpenAI Codex CLI |
| [claude-code](claude-code/) | Delegate coding tasks to Anthropic Claude Code CLI |
